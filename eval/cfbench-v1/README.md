# CF-Bench v1 (Oct 28 – Nov 2, 2026): archived

The first CF-Bench, built from 7 YouTube tutorials under the standard YouTube licence. Its results are in
`summary.md`, and its labels and every recorded model answer are kept here. Its frames are not published, because
we don't have the rights to redistribute frames of those videos: the labels name each source video and time, so
anyone can rebuild the frames from their own copy with `tools/cfbench.py make`.

The current CF-Bench (`../cfbench/`) is built from Creative Commons (CC BY) tutorials, and its frames are published.
