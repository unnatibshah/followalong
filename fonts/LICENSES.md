# Fonts

Self-hosted because the Content Security Policy allows no third-party origins. Latin subset, WOFF2, downloaded from
the Fontsource packages on jsDelivr (`@fontsource/geist-sans@5`, `@fontsource/geist-mono@5`,
`@fontsource/instrument-serif@5`).

| Files | Font | Licence |
|---|---|---|
| `geist-*.woff2` | Geist by Vercel | SIL Open Font License 1.1 |
| `geist-mono-*.woff2` | Geist Mono by Vercel | SIL Open Font License 1.1 |
| `instrument-serif-*.woff2` | Instrument Serif by Instrument | SIL Open Font License 1.1 |

The OFL allows bundling and redistribution with software; the fonts may not be sold on their own.
